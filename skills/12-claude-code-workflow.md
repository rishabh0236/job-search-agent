# Claude Code Workflow
Read CLAUDE.md and relevant skills before coding.
Inspect existing code first.
Plan small changes.
Implement smallest coherent change.
Run targeted tests, formatting and lint.
Update docs when behavior changes.
Do not add dependencies without justification.
Never commit secrets.
Build mock integrations before real browser flows.
Definition of done = implementation + tests + errors + logs + docs + local reproduction steps.
Prefer safe STOP over guessing/submitting.
